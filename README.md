# Fadd Links

## Quick Start

```bash
# Install dependencies
npm install --legacy-peer-deps

# Run development server
npm run dev

# Build for production
npm run build
```

---

## Configuration

- **Profile & Bio**: Edit [`data/BioData.js`](data/BioData.js)
- **Links & Categories**: Edit [`data/LinksData.js`](data/LinksData.js)
- **SEO & Social Previews**: Edit [`next-seo.config.js`](next-seo.config.js)
- **Theme & Colors**: Edit [`styles/theme.config.js`](styles/theme.config.js)
